🌟 key features
🛡️ dm guard & auto-block: automatically warns spammers up to 3 times in private messages and blocks them on the 4th infraction.
📢 global broadcast (.dot): reply to any message with '.' to broadcast it instantly across all dms, groups, and channels with real-time success & fail reports.
🚪 auto leave muted chats (.leavemute): scans all joined groups/channels and automatically exits any chat where sending messages is restricted.
🏷️ batch tagging (.tag <msg>): tags group members in clean batches of 5 users per message.
🎲 random tagging (.randomtag): tags group members one-by-one with randomized casual conversation starters.
🔤 small font formatting: all outgoing status messages, reports, and alerts are auto-formatted into sleek small fonts.
🛡️ anti-ban protection: built-in rate limiting and flood-wait handling designed for large-scale operations (5,000–10,000+ interactions).
